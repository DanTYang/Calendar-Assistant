These meeting notes are fictional. They were written as test data for the
note-search half of this project and describe people, meetings, and a vendor
that do not exist. Nothing here is a real meeting record.

Point NOTES_FOLDER at your own directory of .md files to search real notes:

    NOTES_FOLDER=~/Documents/notes python -m assistant.main

This file is .txt rather than .md so the loader, which globs *.md, does not
index it as a sixth note.
